How we work this out ▾
  • Baseline — Spond: figures compare twoclear with a club currently running bookings on Spond. Both charge the same 2.5% + 20p per card transaction.
  • Card fees saved: because the rate is identical, the 2.5% cancels out — the saving is the fixed 20p on every transaction removed. On Spond each booking is a separate card payment; on twoclear members pre-pay a wallet covering several sessions, so there are far fewer transactions. Fewer transactions × 20p = the saving.
  • Admin time (optional): only counts if you switch it on, because it’s realised through a twoclear plan — so we subtract the subscription to show the true net. twoclear automates court line-ups, RDR ratings and the waitlist, removing about 85% of the hands-on booking admin Spond still leaves per session, valued at your organiser’s hourly rate.
  • Bookings per month = sessions/week × 4.33 × players/session. Figures are estimates to help you compare, not a quote.
