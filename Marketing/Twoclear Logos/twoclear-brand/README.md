# twoclear — brand asset pack

## Colours (exact)
- Navy       #101828
- Orange     #F97316
- Tagline on light backgrounds  #667085
- Tagline on dark backgrounds   #D0D5DD

## Folders
svg/       Vector masters (all text converted to outlines — no fonts required)
png/       Transparent PNG exports (lockups 3000 px wide, icon 1024 px)
favicon/   Square badge at 16, 32, 48, 64, 128, 180, 192, 256, 512, 1024 px + favicon.svg

## Variants
full      badge + wordmark + tagline    light / dark
compact   badge + wordmark              light / dark
wordmark  "twoclear" only               light / dark
icon      square badge only             light / dark

"light" = for light backgrounds (navy artwork).
"dark"  = for dark navy backgrounds (white artwork, white badge with navy 2).
The orange ball is identical in both.

## Typography
Wordmark: Poppins Bold, outlined. Tagline: Poppins Bold, letter-spaced, outlined.

## Usage
- Clear space: at least half the badge height on all sides.
- Minimum size: full lockup 32 px / 12 mm high; compact 20 px / 8 mm; badge 16 px.
- Do not recolour, stretch, add effects or rearrange the elements.
