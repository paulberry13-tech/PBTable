Usage
-----
Light-background assets use the navy wordmark and navy badge.
Dark-background assets use the white wordmark and white badge.
Orange #F97316 is reserved for +2 only.

Typography
----------
Inter, -apple-system, "Segoe UI", Roboto, Helvetica, Arial, sans-serif

Note
----
The SVGs intentionally retain live <text> elements, per the approved brief.
For exact production consistency, install Inter or convert text to outlines in a vector editor before sending to print.
